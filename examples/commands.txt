Hugo — the distilled commands
================================================================
Placeholders: the lab's binary was at
./bin/hugo and its site in ./hilltop;
on your machine `hugo` will usually be
on the PATH. Commands are run from the
project root unless shown otherwise.

INSTALL AND FIRST CONTACT (chapters 3-4)
----------------------------------------------------------------
  curl -LO https://github.com/gohugoio/hugo/releases/download/v0.168.0/hugo_extended_0.168.0_linux-amd64.tar.gz
  curl -LO https://github.com/gohugoio/hugo/releases/download/v0.168.0/hugo_0.168.0_checksums.txt
  grep extended_0.168.0_linux-amd64.tar.gz \
    hugo_0.168.0_checksums.txt | sha256sum -c -
                                   # answer wanted: OK
  tar -xzf hugo_extended_0.168.0_linux-amd64.tar.gz
  hugo version                     # look for +extended
  hugo new site hilltop
  cd hilltop

BUILD AND SERVE (chapters 2, 4)
----------------------------------------------------------------
  hugo                             # build into public/
  hugo --cleanDestinationDir       # ...removing stale output first
  hugo server                      # http://localhost:1313/
  hugo server --buildDrafts        # drafts visible, for preview only

CONTENT (chapter 5)
----------------------------------------------------------------
  hugo new content notes/comet-watch.md
                                   # from the archetype; born a draft
  hugo list all                    # the inventory, as CSV
  hugo list drafts                 # what is being withheld
  hugo list future                 # what is waiting for its date

DIAGNOSIS (chapters 6, 15)
----------------------------------------------------------------
  hugo --templateMetrics           # which templates ran, how often
  find public -type f | sort       # what the build actually made
  grep -o '<loc>[^<]*</loc>' public/sitemap.xml
                                   # every address should start
                                   # with the real baseURL
